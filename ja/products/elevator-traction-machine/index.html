ギアレスエレベーター牽引機：最新のPMSMソリューション
#

ギアレス永久磁石同期モーター（PMSM）エレベーター牽引機は、エレベーター技術における大きな進歩を示しています。効率性、安全性、快適性を追求して設計されており、永久磁石同期モーター、牽引車輪、ブレーキシステムを統合し、エンコーダーによる精密なクローズドループおよび周波数制御を実現しています。

主な特徴
#

  • 高効率＆高性能
    PMSMギアレス牽引機は高効率、低始動電流、大きな始動トルクを誇ります。ギアレス設計により、滑らかで快適な運転、低騒音、高信頼性を実現しています。

  • コンパクト＆軽量
    希土類永久磁石材料を使用し、コンパクトかつ軽量で、多様な設置環境に適しています。

  • 低騒音＆環境配慮
    モーターの騒音レベルは60dB以下。アスベストを含まないブレーキライニングと、様々な作業条件での安定した性能により環境面でも優れています。

  • 安全性＆快適性
    高度なベクトル制御により乗り心地と階床レベリング精度を向上させ、乗客に滑らかで快適な乗車体験を提供します。

  • 自然冷却
    自然冷却設計により、追加の冷却システムなしで信頼性の高い運転をサポートします。

構造とコンポーネント
#

  • モーター筐体：グレー鋳鉄（FC25）製で、優れた振動吸収性と耐久性を持ちます。
  • エンコーダー：モーター軸に事前装着されたインターフェースにより柔軟な構成が可能です。
  • 安全ハンドルホイール：停電時に手動で最寄り階に安全に停止させることができます。
  • ワイヤーロープホイール：球状黒鉛鋳鉄（FCD650）製、硬度HB230～260で耐久性があります。
  • 手動ブレーキ解除：停電時にブレーキを制御して安全にカーポジショニングが可能です。
  • 電磁ブレーキ：100万回以上の動作耐久性、騒音60dB以下。
  • 安全カバー：ワイヤーロープ操作時の誤損傷を防止します。
  • 構造要素：冷間シリコン鋼ステーター（F級絶縁）、NdFeB永久磁石、自動調心ローラーベアリング、QT-700球状黒鉛鋳鉄牽引車輪を採用。

動作条件
#

ギアレスPMSM牽引機はGB/T 13435-1PPZ「エレベーター牽引機」規格の要件を満たすよう設計されており、以下の環境パラメータに対応しています：

  • 室内温度：5～40°C
  • 月間平均相対湿度最大値：90%未満（最低温度25°C以下）
  • 供給電圧変動：定格値の±7%以内
  • 周囲大気に腐食性または可燃性ガスなし
  • 牽引ロープは清潔で潤滑剤や汚染物なし
  • GB / T 7588-2003（第9.3.1b条）に準拠した貨物/カウンターウェイトおよびロープ角度

騒音と振動
#

  • 電気的騒音：60dB以下
  • 振動速度RMS：1mm/s以下
  • 振動加速度：2m/s²以下
  • プーリーねじれ振動：4.5mm/s以下
  • 振幅：15µm以下
