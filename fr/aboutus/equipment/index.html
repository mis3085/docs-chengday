Innovation et Contrôle Qualité dans la Fabrication de Composants
#

Les pièces de l’ours noir sont fabriquées avec des alliages haute résistance et des matières premières de qualité supérieure, utilisant une technologie avancée et des équipements sophistiqués. Le processus de production intègre des centres d’usinage CNC horizontaux, des soudeurs robotisés, des capteurs de numérisation précis et des systèmes automatiques de test pour moteurs, garantissant une cohérence et une qualité maximales. Chaque palan est assemblé, testé et inspecté individuellement selon des normes strictes de contrôle qualité, en utilisant des équipements automatisés.

Équipements d’Inspection et de Tests
#

  • Mesures précises de balayage du capteur de balayage 3D GT 800A
  • Machine d’essai de traction horizontale 150 tonnes.
  • Machine d’équilibrage dynamique numérique

Spécifications :
#

  • Plage de poids de la pièce : 20 – 300kg
  • Poids max. sur chaque support : 500kg
  • Transmission par courroie : 100mm ; Transmission conjointe : 1300mm
  • Distance entre paliers : 2200mm
  • Diamètre de l’arbre : 130mm
  • Vitesse d’équilibrage : Contrôle par variateur (VF-11S TOSHBA)
  • Plage de mesure : 300~20000rpm
  • Sensibilité : 5μ
  • Moteur d’entraînement : 3.5kW (AC 220V 3PH WUTA)

Correction des outils pour l’équilibrage dynamique :
#

  • Φ460 PM machine de traction du rotor Ass’y (poulie / cliquet moyeu de roue / aimant)

  • Φ560 PM machine de traction du rotor Ass’y (poulie / cliquet moyeu de roue / aimant)

  • Pièces de la machine de traction PM

  • Théodolite test de déflexion de palette automobile

  • Autres équipements remarquables :
    • Machine d’essai universelle
    • Testeur ultrasonique USK6
    • NV-30 pointe vectorielle machine d’équilibrage dynamique
    • Mètre de vibration AVT-LE
    • Modèle de testeur de dureté no. 3R
    • Durmètre HT-2000
    • Oscillographie pratique
    • Jauges d’épaisseur
    • Mètre de distance laser
    • Mètre de puissance numérique WT230
    • Calibre de mouvement pour réglage d’équilibre / analyseur Spectrum

Équipements de Fabrication
#

Les pièces sont produites avec une technologie de pointe, incluant des centres d’usinage CNC horizontaux, des soudeurs robotisés et des systèmes automatiques de test pour moteurs. Cela garantit la cohérence et la qualité de chaque composant assemblé.

  • Tour CNC
  • Centre d’usinage horizontal KH-80 CNC
  • Fraiseuse

Principe de fonctionnement :
#

  • La bobine est placée dans le four à 80 ℃ pendant 2 heures.
  • Elle est complètement immergée dans un vernis isolant.
  • Le réservoir auxiliaire est élevé jusqu’au réservoir principal pour le trempage.
  • Le solvant du réservoir principal couvre la bobine, assurant l’isolation par différence de température.
  • La bobine est retirée après séchage.

Applications :
#

  • Stators de différents diamètres pour palans électriques à chaîne et moteurs réducteurs.

  • Perméateur sous vide pression positive / négative

Étapes d’opération :
#
  1. Allumer le tableau de contrôle de puissance et appuyer sur “hydraulique ON”.
  2. Activer les vannes d’entrée et de libération d’air selon la séquence.
  3. Placer les stators dans le réservoir de vernis et fermer le couvercle.
  4. Effectuer le vide et la pressurisation en suivant les temps et pressions indiqués.
  5. Retirer le stator après la fin du processus.
Application :
#

  • Stators à aimant permanent et sans balais pour palans et machines de traction.

  • Machine automatique d’enroulement de stator

Précautions :
#
  • Vérifier le réglage des paramètres d’enroulement.
  • Contrôler le diamètre de la bobine et la hauteur de la pile du stator.
  • Sélectionner les appareils d’enroulement selon la spécification.
Spécifications d’enroulement :
#
  • Φ 90 X 50 L, Φ 90 X 25 L
  • Φ 160 X 45 L, Φ 160 X 30 L
  • Φ 462 X 70 L, Φ 560 X 75 L, Φ 462 X 80 L, Φ 560 X 90 L, Φ 462 X 100 L
Application :
#

  • Moteurs à aimant permanent sans balais, machines synchrones sans engrenage.

  • Four

  • Stator BLFD dans le four : Température 70 ℃ / 12 h

  • Stator BLFD dans le four : Température 120 ℃ / 8 h

  • Stator de traction PM dans le four : Température 120 ℃ / 8 h

  • Système multifonction Bras robotisé de soudage

  • Autres équipements de fabrication :
    • Centre d’usinage vertical MCV-1350
    • Machine de formage d’engrenages
    • Centre d’usinage horizontal MCH-500 / OM
    • Usinage horizontal CM502 de fraises
